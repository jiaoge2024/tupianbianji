🔑 百度OCR API 配置

📖 如何获取 API Key？ ▼
  1. 访问 百度智能云控制台
  2. 注册/登录百度账号
  3. 进入「产品服务」→「文字识别」
  4. 点击「创建应用」
  5. 获取 API Key 和 Secret Key
  6. 将密钥填入上方配置框

⚠️ 安全提示

  • 密钥仅存储在浏览器本地，不会上传到任何服务器
  • 请勿将密钥分享给他人
  • 建议仅在个人设备上使用此功能
  • 如怀疑密钥泄露，请立即在百度云控制台重置
  • 百度 OCR 服务有免费调用额度限制，请合理使用

🎨 Gemini AI 生图配置

📖 如何获取 API Key？ ▼
  1. 访问 Google AI Studio
  2. 登录 Google 账号并创建 API Key
  3. 复制 API Key 填入上方配置框
  4. 返回编辑器点击「AI生图」即可开始生成

⚠️ 安全提示

  • API Key 仅存储在浏览器本地，不会上传到任何服务器
  • 请勿将 API Key 分享给他人
  • 建议仅在个人设备上使用此功能
  • 如怀疑 API Key 泄露，请立即在 Google AI Studio 中重置
  • Gemini 图像生成服务可能产生费用，请合理使用
