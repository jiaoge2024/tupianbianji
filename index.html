🔑 百度OCR API 配置

📖 如何获取 API Key？ ▼
  1. 访问 百度智能云控制台
  2. 注册/登录百度账号
  3. 进入「产品服务」→「文字识别」
  4. 点击「创建应用」
  5. 获取 API Key 和 Secret Key
  6. 将密钥填入上方配置框

⚠️ 安全提示

  • 密钥仅存储在浏览器本地，不会上传到任何服务器
  • 请勿将密钥分享给他人
  • 建议仅在个人设备上使用此功能
  • 如怀疑密钥泄露，请立即在百度云控制台重置
  • 百度 OCR 服务有免费调用额度限制，请合理使用

🎨 ModelScope AI 生图配置

📖 如何获取 API Token？ ▼
  1. 访问 ModelScope 官网
  2. 注册/登录 ModelScope 账号
  3. 点击右上角头像，进入「我的主页」
  4. 在左侧菜单点击「访问令牌」
  5. 点击「创建新的访问令牌」
  6. 复制 Token 填入上方配置框

⚠️ 安全提示

  • Token 仅存储在浏览器本地，不会上传到任何服务器
  • 请勿将 Token 分享给他人
  • 建议仅在个人设备上使用此功能
  • 如怀疑 Token 泄露，请立即在 ModelScope 控制台重置
  • ModelScope 图像生成服务可能产生费用，请合理使用
