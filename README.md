# 极简图片编辑器 (Image Studio)

一款基于 Chrome Manifest V3 开发的极简且专业的浏览器插件图片编辑器。主打"即开即修，本地处理，安全隐私"。

## 核心特性

### 导入方式
- **点击上传**：点击上传区域选择图片
- **拖拽上传**：直接拖拽图片到编辑区域
- **剪贴板粘贴**：使用 Ctrl+V 直接粘贴剪贴板中的图片

### 基础工具
- **裁剪 (Crop)**：支持自由裁剪，内置常用比例（1:1、3:4、4:3、9:16、16:9）
- **尺寸调整 (Resize)**：精确修改宽高像素
- **旋转 (Rotate)**：支持顺时针/逆时针 90°/180° 旋转
- **滤镜 (Filter)**：调整亮度、对比度、饱和度等效果
- **马赛克 (Mosaic)**：画笔式马赛克，可调节笔刷大小，用于遮盖敏感信息

### 高级功能
- **网格切图**：将图片按指定行列数平均切割，自动打包成 ZIP 下载
- **证件照**：AI 一键生成标准证件照，支持多种尺寸规格（1寸、2寸等），可选底色
- **AI 背景替换**：智能抠图移除背景，支持纯色或自定义图片背景

### 标注工具
- **添加箭头**：在图片上添加方向箭头标注
- **添加矩形**：绘制矩形框标注区域
- **添加圆形**：绘制圆形标注区域

### 水印/文字
- **添加文本**：插入自定义文字，可调整颜色、透明度等属性
- **添加图片**：插入图片作为水印，可调整透明度、缩放比例

### 插件工具
- **图标生成**：自动生成浏览器插件所需的多尺寸图标（16x16、32x32、48x48、128x128）

### 状态管理
- **撤销/重做**：支持 Ctrl+Z 撤销和 Ctrl+Y 重做，记录完整操作历史
- **删除图片**：一键删除当前图片并重置编辑器状态

### 导出功能
- **多格式导出**：支持 PNG、JPEG、WEBP 三种格式
- **质量调整**：JPEG/WEBP 格式支持质量参数调整（0.1-1.0）
- **一键下载**：快速下载处理后的图片
- **复制剪贴板**：一键将结果复制到系统剪贴板

### 界面交互
- **可拖拽侧边栏**：左侧工具栏与预览区之间的分隔线支持左右拖拽调整宽度
- **属性面板**：选中工具或已添加内容后，右侧显示对应属性调整面板

## 技术栈

- **核心库**：[Fabric.js](http://fabricjs.com/) - 强大的 Canvas 操作库。
- **AI 辅助**：集成 MediaPipe Selfie Segmentation (可选扩展)。
- **规范**：Chrome Extension Manifest V3。

## 项目结构

```text
├── assets/             # 静态资源
├── lib/                # 第三方依赖库 (Fabric.js, MediaPipe等)
├── scripts/            # 核心业务逻辑
│   ├── main.js         # 主入口逻辑
│   ├── history.js      # 历史记录管理 (Undo/Redo)
│   └── tools.js        # 编辑工具实现
├── styles.css          # 样式表
├── manifest.json       # 插件配置文件
└── index.html          # 编辑器主界面
```

## 安装与使用

1. 下载或克隆本项目到本地。
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目所在的文件夹。
5. 点击插件图标即可开始使用。

## 隐私声明

本项目所有图片处理均在本地浏览器内完成，不会上传到任何服务器，确保您的隐私安全。
